# Historical checkpoints

The current editable model is `../pdinn_jelly.blend`, Library v11. Seven earlier .blend milestones remain in the original Library source ZIP v9; their exact names, sizes and hashes are listed in `../provenance/OMITTED_ARCHIVE_FILES.json`. They are not duplicated in this Git archive. Source ZIP identity/hash is in `../provenance/SOURCE_ARCHIVES.json`.

The historical incremental modeling scripts expect their matching prior inputs. Do not blindly apply them to v11. This directory also allows the final-render script to save its pre-render checkpoint when run on a working copy.
